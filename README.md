# Limitr
Open-source embedded policy engine for usage, seats, and credits, designed for AI, developer tools, and open-source products.

> Stop hard-coding usage limits. Limitr lets you define seat logic, credits, and limits once, in policy, and embed in anywhere.

- Define limits and entitlements in policy, not code
- Works offline, embedded, and self-hosted
- Stripe-agnostic, billing-agnostic
- Built on [Stof](https://docs.stof.dev) (open-source)
